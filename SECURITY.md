# Security

Report a vulnerability privately to support@wakeshift.ai, not in a public issue or pull request. Put "Security" in the subject, and say what's affected and how to reproduce it.

We confirm we got it, keep you told while we fix it, and credit you when the fix ships unless you'd rather we didn't.

We support the latest release. This repository is generated from Wakeshift's main repository, so a fix lands there first and arrives here with the next publish.
